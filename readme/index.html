README · Legs.Beauty

关于美腿的一切！还请先看看这里。

这里算是一个简易的自用书签站（或者叫微导航），收集了一些我经常去的网站/用的工具。

美腿？

站点标题是“美腿”，不过却丝毫没有该类元素，某种意义上也算是在挂羊头卖狗肉了doge，那为什么还要叫美腿呢？其实原因很简单，作为半个域名爱好者，收集了一些域名（用于吃灰），在我正满怀热血地计划者着上线一个书签站，并为之挑选合适的域名的时候，legs.beauty就在身边，它的后缀不太常见，但整体寓意还算清晰，也比较好记忆虽然长度长了些，所以就成了本站域名。

其实一开始也考虑过从其他大佬手里收个专用的导航米，比如nav.xx这样一看就是导航专属的域名，但思来想去还是认为专门为书签站收购一个域名太奢侈了些，所以就将就着用了。
